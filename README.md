# Norte Brunch App v25 - Estable

Versión revisada y simplificada para Norte Brunch.

## Hojas usadas
Solo usa 4 hojas de Google Sheets:
- Productos
- Pedidos
- Movimientos
- Saldos

## Mejoras de esta versión
- Pedidos pendientes con agregar/quitar artículos antes de cobrar.
- Ventas con fecha y hora manual para registrar días anteriores.
- Una sola hoja de movimientos para ventas, gastos, pagos personales, deuda y ajustes.
- Gastos sin categorías.
- Balance operativo: ventas netas contra gastos.
- Balance de deuda separado de ganancias.
- Pago personal solo sábado después de 6:00 pm.
- Diezmo solo se muestra cuando se realiza pago personal.
- Reportes por día de la semana, producto más vendido y producto con más ganancia.
- Reportes por semana, quincena, mes y año.
- Botón de diagnóstico para revisar estructura y datos.
- Menos llamadas a Google Sheets usando caché y append_rows cuando aplica.
